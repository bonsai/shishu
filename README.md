# shishu — 詩集

詩を原稿用紙に、アニメーションで表示する詩集。
組版は bonsai/genkou（400字詰め原稿用紙）の系譜で、文字は1字ずつインクが乗るように現れる。

## 構成

- `index.html` — 表示版（単一ファイル）。詩のJSONを埋め込んでいるので、そのままブラウザで開けば再生される
- `poems/` — 詩の正本（JSON）。1篇1ファイル
  - `poems/white-001.json` — WHITE 作・無題（海馬は荒れに荒れ、…）。385字、3連

## 詩JSONの形式

- `text` — 原文そのまま
- `lines` — 組版の正本（行の配列。著者行は分離して独立行）
- `author` / `title` — 著者と題（無題は null）
- `layout` — 自動ルートの規則
  - PC等（641px以上）: 横20文字 × 20行 ＝ 400字詰め原稿用紙（10mmマス）
  - スマホ（640px以下）: 横10文字 × 40行、マスは画面幅 ÷ 10
  - 改行は次の行頭へ送る。枚（シート）分割は幅ごとに自動計算
- `animation` — 初期速度（ms/字）と枚送りの間

WHITEの詩は、PC組では25行、スマホ組では44行になり、どちらの組でも自動で2枚に収まる。

## 姉妹repo

- bonsai/genkou — 原稿用紙の最小実装（表示の土台）
- bonsai/make-poem — 詩を「作る側」の研究PoC（意味×音の詩語選択）
